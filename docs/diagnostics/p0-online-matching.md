## 准入与恢复策略

- 不复制歌词自动匹配的75分阈值。资料/封面分别检查可用身份字段；缺失信息不足时宁可留给手选，不凭同名推断歌手。
- 同名不同歌手、Live、伴奏、Remix、Cover、Remaster 与已知错误专辑不能被自动应用。原手动歌词检索及评分展示保持可用。
- QQ 简繁/标题回退保留。2001 仅按已有真机证据进行有限变体检索，不解释为限流、封禁或 Safari 故障。403/429/5xx、网络超时不做无条件快速重试。
- 已有嵌入封面不自动替换；已有 URL 会检查可用缓存，缓存缺失可恢复。原 URL 已失败时不立即对同一 URL 重试；继续寻找其他可靠图源。
- 资料成功、封面失败和未找到可靠封面是不同状态。再次执行时，已应用资料的歌曲使用 cover 意图，避免重复覆盖资料。
- 部分底层请求不能接收取消信号；调用方有界停止等待，任务提交检查信号，QQ及封面请求能实际中断。不能保证外部平台从未收到已取消任务此前发出的请求。

## iPad 诊断入口

沿用原 Preview 地址，在查询参数加入 `matchDebug=1&qqLyricDebug=1`。

在“整理歌曲信息”或手动歌曲信息窗口展开“在线匹配诊断”，点“复制诊断”；若剪贴板被拒，点文本框全选后使用系统“拷贝”。QQ 歌词窗口仍有原“QQ 歌词搜索诊断”。删除参数即隐藏。

新通用诊断仅保留当前页面内存最近60条，记录时间、阶段、来源、HTTP/上游码、结果数和结局，不保存原错误文本、Cookie、令牌、音频、文件路径或曲库导出。旧 QQ 诊断保留原有30条查询摘要规则。不上传诊断。

## 验证证据类型

1. **Mock / 单测**：候选准入、三个平台回退、拒绝/异常结构/零结果/超时、QQ脚本回退、缓存失败保护、取消/替换批次、逐首隔离、手工字段保护、OPFS MIME 恢复。
2. **隔离真实代码**：浏览器使用实际匹配、IndexedDB、OPFS、图片解码及 UI；仅网络响应使用合成夹具。验证已有歌词独立补图、刷新恢复、不污染已确认资料、手动失败提示/触屏选择诊断、封面开关预览/保存。
3. **真实在线响应**：另按交付记录列出；受控夹具不算真实网易/QQ/酷狗响应。
4. **iPad Safari 真机**：本轮云端不能替代。外部平台可能拒绝、缺目录或缺图片；尚无《几分之几》第二次拒绝和第二轮批量全失败的真实分阶段日志，不宣称具体平台根因已被证明。

运行结果及提交/部署状态见本次交付说明。构建会提示既有大 chunk 与部分动态导入无法独立分包，不据此宣称性能已在 iPad 验收。

## 最少真机验收

1. 同一现有 Preview、原曲库打开诊断版，给《几分之几》执行缺失封面补全；确认歌名/歌手/专辑/歌词不变。
2. 《幸福不远》用原 QQ 歌词入口搜索默认简体词，核对简繁回退及正确歌词候选。
3. 选少量缺图歌曲做批量，确认每首结果不同；仅让保留勾选的失败/未完成项重试。
4. 对照一首已有正确封面的歌曲应保持不变；刷新或重新进入后核对前述匹配结果。失败时复制诊断即可，不清站点数据、不重新导入。

若浏览器不提供 Cache Storage 或 Worker 控制，播放器仍可使用 OPFS；曲库卡片离线图片恢复需单独以真机结果判断。
