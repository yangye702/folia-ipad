## Concrete fix recommendation

One bounded cleanup fix is justified: reuse `createPaperShaderReleaseRef` in `NomandBackgroundLayer.tsx`. Add `useMemo` to React imports and `createPaperShaderReleaseRef` beside the existing `PAPER_SHADER_CONTEXT_ATTRIBUTES` import. After the existing `shaderRef`, create a stable release callback `useMemo(() => createPaperShaderReleaseRef(shaderRef), [])`; forward that callback in `commonProps.ref`. Keep `useShaderDrawn(shaderRef, ...)` unchanged. This mirrors already-accepted Latent handling (`LatentBackground.tsx:130–131`) and changes no tuning, quality, rendering algorithm, or playback state.

Confirmed source: installed Paper `node_modules/@paper-design/shaders/dist/shader-mount.js:386–418` cancels RAF, deletes textures/program, disconnects observers and removes canvas, but does not lose its WebGL context. Existing `src/utils/paperShaderContext.ts:18–25,28–42` explicitly describes and handles the drawing buffers retained until canvas GC. Nomand's plain ref never invoked this helper. The initial real Chromium probe imported the actual component over the existing dev server into an isolated browser context, rendered a data-URL synthetic cover, waited for `paperShaderMount`, retained canvas/gl references for observation, unmounted its React root and waited 350ms. Result: before `{canvases:1, connected:true, lost:false}`; after `{canvases:0, connected:false, lost:false}`. This proves missing eager context release, **not a permanent leak, heap size, or iPad memory-pressure crash**; retained references deliberately prevent GC to observe whether cleanup explicitly releases.

Implemented exactly the stable release-ref reuse above, with no other production-file changes. New `dev/probes/nomandContextCleanup.probe.tsx` mounts actual Nomand with a synthetic SVG cover in the gallery's existing StrictMode. New `test/component/nomandContextCleanup.spec.ts` checks two effect swaps and final unmount: current attached contexts remain live, detached contexts become lost. Red run failed as intended at replaced-context `isContextLost` expectation, true expected / false observed after 15s; green run passed, 1 test in 16.3s. Existing `test/unit/utils/paperShaderContext.test.ts` also passed 4 tests, including keeping connected canvas live. No full suite or build run, per scope.
