## 最小恢复策略

仅 `searchQQLyrics` 增加有限顺序回退，普通 QQ 搜歌保持原行为：

1. 原词、繁体、简体（去重）。
2. 若输入包含匹配窗口的 ` - ` 分隔符，再尝试歌名及其简繁变体。
3. 最多 6 个不同关键词，有结果立即返回，不合并候选或自动应用歌词。

仅有效零结果或顶层 0 / 子请求 2001 时继续。网络失败、HTTP 错误、格式异常和其他上游码立即报错。
若所有尝试均无歌曲但至少一次被 2001 拒绝，仍报上游失败，不能显示真实零结果。
匿名请求、代理、歌词获取、原搜索框文字、已有匹配评分及本地数据均不改动。

`?qqLyricDebug=1` 的原诊断面板记录每次实际尝试的关键词、响应码与数量，仍仅内存保留最近 30 条，无凭据或响应原文。

## 预览验收

在同一 Vercel Preview 域名保留原音乐，打开 `/?qqLyricDebug=1`，对目标歌曲进入 QQ 歌词匹配，使用默认简体“幸福不远 - 郭书瑶”搜索。
无需手动改繁体；检查候选是否包含郭书瑶 / Honey，选中查看歌词，并复制诊断。
无需保存或重新导入音乐即可验证搜索与预览。失败时保留诊断，不清除网站数据。
